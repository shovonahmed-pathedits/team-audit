# DisputeFiller

এটি একটি Windows ডেস্কটপ অ্যাপ্লিকেশন যা **Tista** প্ল্যাটফর্মে QC (Quality Control) ডিসপিউট তৈরি করার কাজটি স্বয়ংক্রিয় করে। অ্যাপটি **Google Slides** থেকে ডিসপিউটের তথ্য পড়ে এবং Tista-তে স্বয়ংক্রিয়ভাবে জমা দেয়।

- লগইন তথ্য `%USERPROFILE%\Documents\DisputeFiller\config.json`-এ সেভ হয়।

### ধাপ ২: Google Slides লিঙ্ক দিন

```

  - অর্ডার আইডি
  - ভেন্ডর নাম
  - তারিখ
  - মোট পরিমাণ / ত্রুটিগ্রস্ত পরিমাণ
  - ত্রুটির গুরুত্ব (Severity)
  - মন্তব্য

## সেটআপ — প্রথমবার কীভাবে শুরু করবেন

### ধাপ ১: Python ইনস্টল করুন

1. https://www.python.org/downloads/ থেকে Python 3.12+ ডাউনলোড করুন
2. ইনস্টল করার সময় **"Add Python to PATH"** চেক করুন

### ধাপ ২: প্যাকেজ ইনস্টল করুন

এই ফোল্ডারে টার্মিনাল খুলে লিখুন:

```
pip install -r requirements.txt
```

### ধাপ ৩: Google Cloud সেটআপ (একবারই হবে)

1. https://console.cloud.google.com/ যান
2. একটি নতুন প্রজেক্ট তৈরি করুন
3. **Google Slides API** চালু করুন:
   - APIs & Services → Library → "Google Slides API" খুঁজুন → Enable
4. OAuth2 তথ্য তৈরি করুন:
   - APIs & Services → Credentials → Create Credentials → OAuth 2.0 Client IDs
   - Application type: **Desktop app**
   - Name: `Dispute Filler`
5. JSON ফাইল ডাউনলোড করে `credentials.json` নাম দিন
6. এই পাথ-তে রাখুন:
   ```
   C:\Users\<আপনার নাম>\Documents\DisputeFiller\credentials.json
   ```

### ধাপ ৪: অ্যাপ চালু করুন

```
pythonw DisputeFiller.pyw
```

অথবা `DisputeFiller.pyw`-তে ডাবল ক্লিক করুন।

## AI দিয়ে কোড আপডেট করার নির্দেশনা

যদি আপনি নন-কোডার হন এবং AI ব্যবহার করে এই অ্যাপে কিছু পরিবর্তন করতে চান, নিচের ধাপগুলো অনুসরণ করুন:

সম্পূর্ণ কোড মাত্র একটি ফাইলে আছে:

```

```

এই একটি ফাইলেই GUI, লগইন, Google Slides পড়া, Tista-তে জমা দেওয়া — সব কিছু আছে।

### ধাপ ২: AI-কে পরিষ্কার নির্দেশনা দিন

AI-কে (যেমন ChatGPT, Claude, অথবা এই opencode) বলার সময় এভাবে বলুন:

```
উদাহরণ ১: "DisputeFiller.pyw ফাইলে একটি নতুন বাটন যোগ করো যেটা 
সব ডিসপিউটের স্ট্যাটাস রিসেট করবে।"

উদাহরণ ২: "সেভ করা পাসওয়ার্ড base64-এ আছে, এটাকে আরো 
নিরাপদ করার উপায় কি?"

### ধাপ ৩: পরিবর্তন করার আগে

1. **ব্যাকআপ নিন** — `DisputeFiller.pyw` ফাইলটি কপি করে রাখুন

3. **ছোট ছোট পরিবর্তন করুন** — একবারে অনেক কিছু পরিবর্তন করবেন না

### ধাপ ৪: AI-কে দেওয়ার জন্য গুরুত্বপূর্ণ তথ্য

AI-কে নিচের তথ্যগুলো দিলে সে ভালো কাজ করবে:

## AI Coderদের জন্য গুরুত্বপূর্ণ সতর্কতা

> **⚠️ নতুন AI Coderদের জন্য বিশেষ নোট:**

### ১. কোড স্ট্রাকচার

- সম্পূর্ণ অ্যাপ **একটি মাত্র ফাইল** (`DisputeFiller.pyw`-তে আছে — প্রায় ২৪০০ লাইন। এটি একটি monolithic ফাইল, modular নয়।
- `DisputeFillerApp` ক্লাস (`ctk.CTk` থেকে inherit) সব কিছু handle করে।
- কোনো ডাটাবেস নেই — সব data RAM-এ থাকে এবং JSON ফাইলে সেভ হয়।

### ২. Tista Integration

- Tista-র কোনো formal API নেই — অ্যাপটি **HTML scraping** করে (HTTP GET/POST দিয়ে HTML পড়ে তথ্য বের করে)।
- CSRF টোকেন প্রতিবার নতুন করে নিতে হয় (HTML থেকে regex দিয়ে বের করা হয়)।
- Tista-র page structure পরিবর্তন হলে কোড ভেঙে পড়তে পারে — এটি সবচেয়ে সাধারণ সমস্যা।

### ৩. Google Slides Integration

- Google Slides API v1 ব্যবহার করা হয়েছে।
- OAuth2 Desktop flow ব্যবহার করা হয়েছে — browser-এ consent popup আসে।
- Token auto-refresh হয়।

### ৪. থ্রেডিং এবং UI

- সব background কাজ **daemon thread**-এ চলে।
- UI update করতে হলে `self.after(0, callback)` ব্যবহার করতে হয় (main thread-এ)।
- `ThreadPoolExecutor` duplicate check-এর জন্য ব্যবহৃত হয়েছে (max 5 workers)।

### ৫. কনফিগ এবং নিরাপত্তা

- Passwords **base64-encoded** — এটি encryption নয়, শুধু obfuscation।
- Config `%USERPROFILE%\Documents\DisputeFiller\`-এ থাকে (hidden folder)।
- `credentials.json` এবং `note.txt`-তে Google OAuth secrets আছে — **এগুলো কখনো git-এ commit করবেন না**।

### ৬. কোড পরিবর্তন করার সময়

- Regex patterns পরিবর্তন করার সময় সতর্ক থাকুন — অনেক জায়গায় HTML parsing regex দিয়ে হয়েছে।
- Tista-র HTML structure পরিবর্তন হলে regex update করতে হবে।
- Error handling বাদ দেবেন না — অনেক জায়গায় try/except fallback আছে।
- `debug_last_page.html` ফাইল তৈরি হয় যখন fulfillment search ব্যর্থ হয় — এটি debug-এ সাহায্য করে।

### ৭. পরীক্ষা করার পদ্ধতি

কোড পরিবর্তনের পর:
1. অ্যাপ চালু করুন — ক্র্যাশ হচ্ছে কিনা দেখুন
2. Login page ঠিকমতো আসছে কিনা দেখুন
3. Google Slides লোড করে দেখুন
4. একটি ডিসপিউট submit করে দেখুন
5. Console log-এ ভুল আছে কিনা দেখুন
